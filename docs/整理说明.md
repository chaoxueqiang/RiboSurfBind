# paper_code2 整理说明

本目录是最终模型的可复现代码整理版。原 `paper_code` 和 `my_mvrbind`
未修改。按照后续清理要求，本目录中的 `.archive/` 历史副本、一次性迁移
脚本和重复文件已删除；需要恢复历史内容时，可从原 `paper_code` 取回。
正式训练数据、论文检查点和结果保留。

## 已整理

- 根目录只保留三个用户入口：训练、评估、新 RNA 预测。
- 模型拆为残基分支、表面分支和整体融合，不执行历史第三分支。
- 三种官方数据协议共用训练循环，分别保留实际划分、样本顺序和损失细节。
- 配置不再依赖“双分支候选”等历史目录，也不读取服务器外部代码。
- 取消源码字符串替换、动态 exec 和实验脚本间修改全局变量的训练方式。
- 保留五项消融及三项敏感性分析，统一用参数配置运行。
- 数据统一为记录、嵌入、注意力、表面缓存和明确划分；不再要求旧136维输入。
- 论文使用的55组模型检查点集中归档，保留来源与SHA-256校验值。
- 删除本目录中的旧逐epoch权重及非论文候选脚本副本，不再保留本地归档。
- 删除未启用的MSA/136维表面输入及可选第二隐藏层代码；保留必要兼容层。
- 训练环境、ERNIE特征提取环境、旧版PyMesh环境、PyMOL可视化环境分离。
- 新增完整epoch边界续训状态，旧模型权重不冒称可直接断点续训。

## 没有改变

标签、序列、划分、有效核苷酸、残基坐标、表面归属及实际特征缓存不变。
模型预测函数、检查点参数值不变。正文和论文图表没有在本次整理中修改。
TL12/JL10仍是已有论文对应版本与实际五个seed，不把后续新实验混入。

## 验证边界

详见两个equivalence报告、快速测试和命令行测试报告。CPU检查不等于
在全部GPU环境重新训练验证；没有启动正式100轮实验，也未停止或修改
原目录下的训练任务。
